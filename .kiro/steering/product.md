# Product Overview

更新日: 2026-08-27

Helpoは、社内制度に関する繰り返しの問い合わせを、登録済みFAQに基づくセルフサービスへ置き換える社内向け質問支援プロダクトである。一般社員と管理者社員を対象とし、総務担当者への個別問い合わせを減らしながら、根拠の明確な案内を提供する。

## Core Capabilities

- 認証済み社員に限定した社内情報へのアクセス
- 登録済みFAQのみを根拠とする質問回答
- 本人の質問履歴と回答評価
- 全社員向けFAQ閲覧
- 管理者社員によるFAQ登録・修正

## Target Use Cases

- 社員が就業規則、休暇、福利厚生などの社内制度を自然文で確認する。
- 過去に行った質問と回答を本人が再確認する。
- FAQを直接閲覧して、よくある質問への回答を確認する。
- 管理者社員が回答根拠となるFAQを追加・訂正する。

## Value Proposition

- 回答根拠を管理されたFAQに限定し、推測による社内情報の提示を避ける。
- 社員が必要な情報を自ら確認できるようにし、総務の定型問い合わせ対応を削減する。
- 質問履歴とGood/Bad評価により、利用者自身の再確認と将来の改善材料を提供する。

## Product Boundaries

対象外はユーザー管理、パスワードリセット、FAQ削除、分析ダッシュボード、総務への問い合わせ受付、社外公開、音声入力、スマートフォン最適化である。これらを追加する場合は独立した仕様として扱う。
