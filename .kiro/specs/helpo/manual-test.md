# 手動テスト項目

## 対象

タスク3「ログインから認証体験を完成させる」の画面確認。

## テスト用アカウント

| ロール | 社員ID | パスワード |
|---|---|---|
| 一般社員 | `E001` | `employee-pass` |
| 管理者社員 | `A001` | `admin-pass` |

## 事前準備

1. `pnpm dev`を実行する。
2. 表示されたローカルURLをブラウザで開く。
3. テストケース間で認証状態や失敗回数を初期化する場合は、ページを再読み込みする。

## ログイン画面

### MT-LOGIN-01 初期表示

- [ ] 未認証状態でログイン画面が表示される
- [ ] 社員ID入力欄が表示される
- [ ] パスワード入力欄が伏字表示になっている
- [ ] ログインボタンが表示される
- [ ] 質問内容、FAQ、質問履歴などの社内情報が表示されない

### MT-LOGIN-02 一般社員のログイン成功

1. 社員IDに`E001`を入力する。
2. パスワードに`employee-pass`を入力する。
3. ログインを押す。

- [ ] 質問画面へ移動する
- [ ] 「社内制度について質問」が表示される
- [ ] ログインエラーが表示されない

### MT-LOGIN-03 管理者社員のログイン成功

1. ページを再読み込みする。
2. 社員IDに`A001`を入力する。
3. パスワードに`admin-pass`を入力する。
4. ログインを押す。

- [ ] 質問画面へ移動する
- [ ] 「社内制度について質問」が表示される
- [ ] ログインエラーが表示されない

### MT-LOGIN-04 パスワード誤り

1. ページを再読み込みする。
2. 社員IDに`E001`を入力する。
3. 誤ったパスワードを入力する。
4. ログインを押す。

- [ ] ログイン画面に留まる
- [ ] 「社員IDまたはパスワードが正しくありません」と表示される
- [ ] 質問画面や社内情報が表示されない
- [ ] 入力した社員IDとパスワードが保持される

### MT-LOGIN-05 存在しない社員ID

1. ページを再読み込みする。
2. 社員IDに`UNKNOWN`を入力する。
3. 任意のパスワードを入力する。
4. ログインを押す。

- [ ] ログイン画面に留まる
- [ ] 「社員IDまたはパスワードが正しくありません」と表示される
- [ ] アカウントの存在有無を推測できる別文言が表示されない

### MT-LOGIN-06 連続失敗1〜4回

1. ページを再読み込みする。
2. 社員IDに`E001`を入力する。
3. 誤ったパスワードで4回ログインする。

- [ ] 各回で「社員IDまたはパスワードが正しくありません」と表示される
- [ ] 4回目まではロック文言が表示されない
- [ ] 4回目までログインを再試行できる

### MT-LOGIN-07 5回目の失敗によるロック

1. MT-LOGIN-06から続けて、誤ったパスワードで5回目のログインを行う。

- [ ] 「ログインに5回失敗したため、10分間ロックされました」と表示される
- [ ] 質問画面へ移動しない

### MT-LOGIN-08 ロック中の正しいパスワード

1. MT-LOGIN-07から続けて、パスワードを`employee-pass`へ変更する。
2. ログインを押す。

- [ ] 正しいパスワードでもログインできない
- [ ] 「ロック中です」と表示される
- [ ] 質問画面へ移動しない

### MT-LOGIN-09 10分経過後のロック解除

1. MT-LOGIN-07のロック開始から10分以上待つ。
2. 社員IDに`E001`、パスワードに`employee-pass`を入力する。
3. ログインを押す。

- [ ] ログインが成功する
- [ ] 質問画面へ移動する

### MT-LOGIN-10 ログアウト

1. 一般社員または管理者社員でログインする。
2. 質問画面のログアウトを押す。

- [ ] ログイン画面へ移動する
- [ ] 質問画面の内容が表示されない
- [ ] ブラウザの戻る操作や保護画面への再アクセスで社内情報が表示されない

### MT-LOGIN-11 ログイン済みでログイン画面へアクセス

1. ログインを成功させる。
2. アプリ内でログイン画面への表示を要求する。

- [ ] ログイン画面ではなく質問画面が表示される

## セッション期限

### MT-SESSION-01 24時間未満

1. ログインを成功させる。
2. ログインから24時間未満の状態で保護画面へアクセスする。

- [ ] 認証済み状態が維持される
- [ ] 対象の保護画面が表示される

### MT-SESSION-02 24時間ちょうど以降

1. ログインを成功させる。
2. ログインから24時間以上経過後に保護画面へアクセスする。

- [ ] セッションが終了する
- [ ] ログイン画面が表示される
- [ ] 共通ナビゲーションや社内情報が表示されない

## 現時点の手動確認上の制約

- 10分ロックは実時間経過で確認できるが、現在の画面には時刻を進める開発者向け操作がない。
- 24時間境界は画面だけで短時間に確認できない。境界値自体は自動テストで検証している。
- 履歴、FAQ閲覧、FAQ管理は現時点では画面骨格のみであり、後続タスクの対象となる。
